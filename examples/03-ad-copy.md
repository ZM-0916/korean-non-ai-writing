# 예시 3. 광고 카피 (G7)

## 원문 (AI 초안)

✨ 혁신적인 기술로 완성한 완벽한 보습! 피부 고민, 이제 더 이상 걱정하지 마세요. 단 한 번으로 놀라운 변화를 경험해 보세요.

## 작성 결과 (방향이 다른 3안)

판독: G7 광고 카피 · 해요체 · 독자 건성 피부 20~30대 · 샘플 없음

1. 혜택형
   - 헤드라인: 세안 후 당김, 아침까지 덜하게
   - 서브카피: [보습 지속 시간 시험 결과, 시험 기관, 시험 조건]
   - CTA: 제품 자세히 보기
2. 문제 제기형
   - 헤드라인: 크림을 덧발라도 오후면 건조한가요?
   - 서브카피: [주요 성분과 함량]
   - CTA: 성분표 확인하기
3. 근거형
   - 헤드라인: [시험 수치]시간 보습, 시험으로 확인했어요
   - 서브카피: [시험 기관·대상 인원·기간]
   - CTA: 시험 결과 보기

주요 변경
- D4 과장 어휘("혁신적인", "완벽한", "놀라운") 삭제
- 화장품은 규제 업종. "단 한 번으로", "완벽한 보습" 같은 효과 보장 표현은 `[규정 확인]` 대상이라 새 안에서 쓰지 않음
- J5 이모지는 SNS 집행이면 허용되므로 브랜드 가이드에 맞춰 추가
- 수치가 없어 대괄호로 자리만 표시
